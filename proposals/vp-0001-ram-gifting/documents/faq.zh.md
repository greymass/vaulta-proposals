# VP-0001 问答

每个回答都可以单独阅读。每个回答先给出直接答案，再给出其背后的数字。除非回答另有说明，数字均截至 2026-10-17。VP-0001 创建一个网络所有的账户 `gift.vaulta`，它持有 1,000,000,000 字节的 RAM，并允许经 BP 批准的创建者将这些 RAM 赠送给他们所创建的账户。

## 对 RAM 价格和 VaultRAM 的影响

该计划的设计是不干扰 RAM 市场，它不对价格作任何预测。除了 `eosio` 在创建 `gift.vaulta` 时购买的 4,096 字节之外，它不从 RAM 市场购买任何 RAM，也不向市场出售任何 RAM。其 1,000,000,000 字节的初始注资是网络已经拥有的 RAM，通过 `ramtransfer` 从 `admin.grants` 转移到 `gift.vaulta`。此后每笔赠送都会将这部分现有供应中的一部分锁定到一个新账户中。接收方不能出售或转让被赠送的 RAM，其唯一的退出方式是返还给 `gift.vaulta`，因此其中任何部分都不会经由接收者进入市场。按 2026-10-17 每 KiB 0.346930 EOS 的价格，全部初始注资价值约 338,800 EOS。

## fund.wram 及其 42 GiB

初始注资来自 `admin.grants`，这是一个已经处于 BP 控制下的账户，本计划不触动 `fund.wram` 及其持有的 42 GiB RAM。将 `fund.wram` 用于任何用途都需要单独的提案和 15/21 BP 的批准，因为它的 `owner` 和 `active` 权限都直接或通过 `eosio.grants` 要求 `eosio@active`，且其 `active` 还需要 `eoslabs.io` 的批准。补充注资也是一个遥远的问题：如果截至 2026-10-17 的 90 天内在 Vaulta 上创建的每个账户都通过本计划创建，按该速度初始注资可以维持将近九年。届时 BP 将就任何补充注资重新讨论，并按其本身的利弊作出判断。

## 女巫账户与空投刷号

刷号行为按创建者受到限制。每个创建者都有每日字节额度，默认为 256 KiB，无论其注册检查如何被绕过，该额度都限制了它每天能花费的捐赠资金：按最小赠送量计算，约为每天 150 个账户。被赠送的 RAM 不能出售，因此赠送永远不会转化为代币。

创建者自行负责其女巫防护。他们的申请需说明如何验证真实用户、按每人、每台设备、每个 IP 地址和每天设定何种上限，以及如何检测和制止滥用。如果某个创建者的检查失效，八名 BP 可以暂停该创建者，十一名 BP 可以停止整个计划。

## 为什么由网络为账户创建出资

它让钱包和应用能够提供免费、即时的账户创建，且自身无需承担成本。一个最简账户在系统提供的 1,400 字节免费额度之外还需要 1,596 字节 RAM，按 2026-10-17 的价格约为 0.54 EOS，由其创建者支付。被接纳为创建者的钱包或应用则改为在每日额度内从 `gift.vaulta` 赠送这部分 RAM。网络的成本很小：截至 2026-10-17 的 90 天内在 Vaulta 上创建的全部 11,082 个账户总共会使用 28.4 MB，即初始注资的 2.8%。这些 RAM 已经归网络所有，原本预留用于资助（grants）。

## 现有的免费账户提供方

任何创建账户的钱包或应用都可以申请成为创建者，包括已经免费赠送账户并自行支付每个账户 RAM 的服务。获得准入后，创建者即可在每日额度内从 `gift.vaulta` 向其创建的账户赠送 RAM。
