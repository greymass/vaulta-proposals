# 제안 렌더링 시스템 시연

[English](proposal.md) | [한국어](proposal.ko.md) | [中文](proposal.zh.md)

## 요약

이 제안은 `demo` 브랜치에 존재하며, 제안 렌더링 시스템의 모든 기능을 하나의 문서에서
시연합니다: 모든 단계의 제목, 표, 코드, 이미지, 제안 간 링크, 비라틴 문자 제목,
그리고 실시간 온체인 바인딩까지 포함합니다. `master`에는 병합되지 않으며 어떠한
거버넌스 효력도 갖지 않습니다.

## 렌더링 기능

인라인 `code`, **굵게**, *기울임*.

### 표

| 기능 | 소스 | 렌더링 주체 |
| --- | --- | --- |
| 마크다운 본문 | `proposal.md` | `VpMarkdown` |
| Msig 바인딩 | 프런트매터 `msigs` | msig 카드 |
| 감성 바인딩 | 프런트매터 `sentiment` | 토픽 카드 |

### 코드

```json
{ "vp": "VP-9999", "purpose": "demonstration" }
```

### 한국어 제목

VPS-1 GFM 규약에 따라 한국어 텍스트에서도 제목 id가 유지되어야 합니다.

### 中文标题

중국어 텍스트에서도 동일하게 적용됩니다.

#### 심화 제목

5단계와 6단계가 아래에 이어지며 제목 목록을 완성합니다.

##### 더 깊은 제목

5단계 제목은 4단계와 같은 굵기로 더 작게 표시됩니다.

###### 最深标题

6단계 제목은 여기에서 중국어 텍스트를 사용하므로 가장 깊은 제목 id가 비라틴 문자입니다.

## 상호 참조

이 시연 문서는 [VP-0001](../vp-0001-ram-gifting/proposal.md)과 표준 자체의 고정된
리비전을 인용합니다: [VPS-1](https://github.com/greymass/vaulta-proposals/blob/07a0a53c46c9dc83b295f7471b5738dba244882a/standard/VPS-1.md).

## 온체인 바인딩

프런트매터는 활성 msig 하나와 감성 토픽 하나를 바인딩하므로, 문서 아래의 카드는
실시간 데이터를 렌더링합니다. 프런트매터가 기준이며, 본문은 참고용입니다.
